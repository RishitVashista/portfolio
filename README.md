 # Rishit Vashist — Portfolio

A modern, responsive personal portfolio built from scratch with pure HTML, CSS, and JavaScript. Features a daily work log powered by Supabase, so I can track my consistency publicly.

🔗 **Live:**  https://rishitvashista.github.io/portfolio/

## ✨ Features

- **Dark developer-themed UI** — deep navy background with a cyan accent
- **Fully responsive** — works on mobile, tablet, and desktop
- **Smooth animations** — fade-in on scroll, floating hero glow, hover transitions
- **Daily Work Log** — public calendar where every day I build is marked with a green tick
  - PIN-protected editor (only I can write)
  - Backed by Supabase (Postgres + REST API)
  - Entries auto-lock at midnight
  - Anyone can read — only owner can write
- **Live project cards** — click any project to open the deployed app
- **No frameworks, no build step** — pure HTML/CSS/JS
